# Front-end web & mobile

These services help you **build, host and test** websites and mobile apps.

**Real-life comparison:** If the back end is the restaurant kitchen, the front end is the dining room customers see. These services help you build the dining room, check it works for every kind of customer, and add useful extras like maps.

## Services in this category

| Service | Level | What it does |
|---------|-------|--------------|
| [AWS Amplify](amplify.md) | 🟢 | Build and host web and mobile apps quickly |
| [AWS Device Farm](device-farm.md) | 🟡 | Test your app on real phones and browsers |
| [Amazon Location Service](location-service.md) | 🟡 | Maps, addresses and tracking for your app |
