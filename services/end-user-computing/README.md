# End-user computing

These services give people **desktops and apps over the internet**, so they can work from any device.

**Real-life comparison:** Instead of giving every worker a powerful PC, you give them a window (any laptop or tablet) into a powerful computer kept safely in a data centre.

## Services in this category

| Service | Level | What it does |
|---------|-------|--------------|
| [Amazon WorkSpaces](workspaces.md) | 🟡 | Cloud desktops (Windows or Linux) you log in to from anywhere |
| [Amazon AppStream 2.0](appstream.md) | 🔴 | Streams individual desktop apps to a web browser |

> For first-line IT folk: think of these as the cloud version of a Citrix or Remote Desktop Services setup.
