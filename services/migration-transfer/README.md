# Migration & transfer

These services help you **move** servers, databases and files from your own data centre (or another cloud) into AWS.

**Real-life comparison:** Moving to AWS is like moving house. You make an inventory (discovery), choose what to move how (planning), pack and drive the big furniture (servers and databases), and post the small boxes (files).

## Services in this category

| Service | Level | What it does |
|---------|-------|--------------|
| [AWS Application Migration Service](application-migration-service.md) | 🟡 | Copies whole servers into AWS |
| [AWS Database Migration Service](database-migration-service.md) | 🟡 | Moves databases into AWS with little downtime |
| [AWS DataSync](datasync.md) | 🟡 | Copies large amounts of files to and from AWS |
| [AWS Transfer Family](transfer-family.md) | 🟡 | SFTP/FTP file transfer straight into S3 or EFS |
| [AWS Migration Hub](migration-hub.md) | 🔴 | Tracks progress of a migration in one place |

## The "7 Rs" of migration (in short)

**Rehost** (lift and shift), **Replatform** (small tweaks), **Refactor** (rebuild for the cloud), **Repurchase** (switch to SaaS), **Relocate**, **Retain** (keep for now) and **Retire** (switch off).
